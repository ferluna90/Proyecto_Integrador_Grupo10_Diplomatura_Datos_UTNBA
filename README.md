# Proyecto Integrador Final (módulo 10)
## Grupo N°10
## Diplomatura en Ciencia de Datos y Análisis Avanzado - Universidad Nacional Tecnológica Buenos Aires

Este repositorio presenta el material utilizado para el Proyecto Integrador Final del Grupo N°10 (cohorte 2026).

## Cómo ejecutar el análisis

La fuente utilizada es el dataset de Credit Risk (https://www.kaggle.com/datasets/laotse/credit-risk-dataset/data), el cual se encuentra publicado en Kaggle. Es un dataset público de uso educativo que simula datos de un buró de crédito (licencia CCO 1.0).

Debe descargarse a una carpeta local con el nombre `credit_risk_dataset.csv`.

En la misma carpeta, deben descargarse los archivos `.ipynb` de este repositorio:
- `Proyecto_Final_Integrador` contiene el código referido al plan y consignas del análisis del Proyecto Integrador Final.
- `Prueba_relevancia_var_grade_rate` presenta un análisis de sensibilidad adicional considerando variables excluidas en el análisis principal.

Cada `ipynb` contiene bloques de texto que comentan e interpretan paso a paso el análisis.

El código es ejecutable en Google Colab y puede ejecutarse en otro intérprete en local.
